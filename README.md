Embedded-разработчик
--------------------
Я являюсь C++ разработчиком с опытом более 2-х лет в прикладном ПО и embedded-системах (ATmega328p, STM32, ESP8266/32). Пишу высокоэффективный код с акцентом на оптимизацию памяти и производительности. Глубокие знания STL, многопоточности, low-level программирования. Глубокие знания в электротехнике и схемотехнике. Активно слежу за развитием стандартов C++. В настоящее время работаю инженером-программистом в АО НПК "Уралвагонзавод", разрабатываю автоматизированные системы управления предприятием на Delphi и postgreSQL(Разработка прикладного ПО, оптимизация SQL-запросов, проектирование БД). Вне работы решаю задачи на LeetCode, увлекаюсь embedded-электроникой, собираю умные устройства на STM32 и ESP32 и разрабатываю прикладное ПО на фреймворке Qt.
